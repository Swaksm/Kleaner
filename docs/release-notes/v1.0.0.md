**Kleaner 1.0, the first stable version.** A free Windows cleaner that tells you what you can delete, and what breaks if you do.

## Download

- **[Installer: kleaner-setup.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.0.0/kleaner-setup.exe)** (recommended): Start menu shortcut, uninstall from Windows Settings → Apps.
- **[Portable version: kleaner.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.0.0/kleaner.exe)**: a single file, nothing to install.
- Download page: **[swaks.org/kleaner](https://swaks.org/kleaner/)** · Scoop: `scoop install kleaner` (bucket in this repo).

Windows 10 or 11, 64-bit. Kleaner is not signed yet: if Windows says “Windows protected your PC”, click **More info**, then **Run anyway**. Each file has its SHA-256 next to it.

## What it does

- **Cleans what is safe**: Windows temporary files, browser caches (you stay logged in), Windows Update cache, Recycle Bin, crash dumps, plus over 1,100 programs from the community catalog. Nothing is ticked in advance, and “Clean risk-free” shows the exact list before anything is deleted.
- **Explains every large file**: each one gets a verdict (safe to delete, uninstall it, breaks something, your files, system, unknown) with what it is and what happens if you delete it. With no rule, the verdict is “unknown”: Kleaner never guesses.
- **Finds the rest**: leftovers of uninstalled programs, duplicates, old code project folders, a photo & video browser, a disk map.
- **Keeps your PC in shape**: programs at startup, broken shortcuts, ghost entries in the programs list, a read-only health & security check-up, Windows and app updates.
- **Starts with Windows if you want**: an icon near the clock that warns you when a drive is almost full. It never scans or cleans by itself.

## Safe by design

- Your own files only go to the Recycle Bin, and the log can bring them back.
- Permanent deletion is limited to a public list of caches, checked in Rust and covered by tests.
- No account, no ads, no telemetry, no network (except an optional update check, off by default). Kleaner never touches passwords, cookies or sessions, and never “cleans” the registry.
