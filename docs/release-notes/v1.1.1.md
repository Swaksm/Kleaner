**Kleaner 1.1.1.** A guided tour, smoother updates, and two fixes.

## Download

- **[Installer: kleaner-setup.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.1.1/kleaner-setup.exe)** (recommended): Start menu shortcut, uninstall from Windows Settings → Apps.
- **[Portable version: kleaner.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.1.1/kleaner.exe)**: a single file, nothing to install.
- Download page: **[swaks.org/kleaner](https://swaks.org/kleaner/)** · Scoop: `scoop install kleaner` (bucket in this repo).

Windows 10 or 11, 64-bit. Kleaner is not signed yet: if Windows says “Windows protected your PC”, click **More info**, then **Run anyway**. Each file has its SHA-256 next to it.

## What's new

- **Guided tour**: on first launch, a short step-by-step tour dims the app and points at the main buttons. Skip it any time (link or Esc), replay it from Settings.
- **Updates without the setup wizard** (installed version): “Install the update” now installs with only a progress bar, then reopens Kleaner. Windows still asks for administrator rights once. This applies to updates made from 1.1.1 onwards.

## Fixes

- A `target` folder next to a `Cargo.toml` is now recognised as a Rust build folder (“Safe to clean”), no longer as your personal files.
- “Move…” now refuses folders that are part of a code project or contain one (`.git`, `Cargo.toml`, `package.json`…): moving them would break the project. Their build folders are deleted safely from Old projects.
