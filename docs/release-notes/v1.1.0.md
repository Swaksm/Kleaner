**Kleaner 1.1.** Eight languages, one-click updates, and two new ways to free space safely.

## Download

- **[Installer: kleaner-setup.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.1.0/kleaner-setup.exe)** (recommended): Start menu shortcut, uninstall from Windows Settings → Apps.
- **[Portable version: kleaner.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.1.0/kleaner.exe)**: a single file, nothing to install.
- Download page: **[swaks.org/kleaner](https://swaks.org/kleaner/)** · Scoop: `scoop install kleaner` (bucket in this repo).

Windows 10 or 11, 64-bit. Kleaner is not signed yet: if Windows says “Windows protected your PC”, click **More info**, then **Run anyway**. Each file has its SHA-256 next to it.

## What's new

- **Russian and Chinese (simplified)**: Kleaner now speaks 8 languages. The explanations of every file, the cleanup list and the health check-up are translated too, not only the interface.
- **One-click update** (installed version): “Install the update” downloads the new installer, checks its SHA-256 against the one published with the release, then installs it. The portable version still opens the download page. Only on click: Kleaner never updates by itself.
- **Leftovers right after an uninstall**: when you uninstall a program from Kleaner, its leftover folders (named after it or its publisher, used by no other installed program) are offered as soon as it is gone, ticked and ready for the Recycle Bin.
- **Move a large folder to another drive**: in Scan, large folders inside Desktop, Documents, Downloads, Pictures, Music or Videos get a “Move…” button. Kleaner copies the folder, reads back every copied file to check it is identical, and only then removes the original. It refuses folders that are open, contain links, online-only OneDrive files or an installed program. The Log can put the folder back.
- **Space freed so far**: the Home page shows how much Kleaner has freed since you started using it (cleanups only, read from the log).

## Safe by design

Nothing changes here: your files only go to the Recycle Bin, permanent deletion is limited to a public list of caches, and there is no account, ads or telemetry. The only network access is the optional update check and, on click, the update download.
