**Kleaner 1.2.** Tips, preinstalled apps, a restore point before heavy cleanups, and a faster, smoother app.

## Download

- **[Installer: kleaner-setup.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.2.0/kleaner-setup.exe)** (recommended): Start menu shortcut, uninstall from Windows Settings → Apps.
- **[Portable version: kleaner.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.2.0/kleaner.exe)**: a single file, nothing to install.
- Download page: **[swaks.org/kleaner](https://swaks.org/kleaner/)** · Scoop: `scoop install kleaner` (bucket in this repo).

Windows 10 or 11, 64-bit. Kleaner is not signed yet: if Windows says “Windows protected your PC”, click **More info**, then **Run anyway**. Each file has its SHA-256 next to it.

## What's new

- **Tips** (More tools): simple rules, no AI. Installers and `.iso` images downloaded more than 30 days ago, archives you already extracted, Steam games not played for 6 months. Files go to the Recycle Bin; games are uninstalled by Steam itself.
- **Preinstalled apps** (Programs): remove Candy Crush, TikTok, News, Weather, Xbox… for your account only. The list is closed: the Store, Edge, Photos, Calculator, Notepad, drivers and Windows components are never offered. Nothing is ticked for you, apps with a side effect say so (Xbox and Game Pass, Game Bar, alarms…), and each one can be reinstalled from the Microsoft Store.
- **Restore point before heavy cleanups**: Windows.old, DISM, hibernation, CompactOS… now create a Windows restore point first (ticked by default). If Windows can't create one, Kleaner asks before going on.
- **CompactOS**: a new heavy cleanup that compresses Windows files (2 to 5 GB on most PCs). It can be undone.
- **Filters in Scan**: filter the largest files and folders by name, verdict or age.
- **Monthly reminder** (start with Windows): at most once a month, a notification says how much the risk-free cleanups would free, when it is over 1 GB. It can be turned off in Settings. Kleaner still never cleans by itself.
- **Better explanations**: 16 new rules with their official source shown in the verdict card (Xbox and Riot games, AMD installer files, Go, Yarn, NuGet, Cargo, Unity, Adobe media cache, Epic, Teams, JetBrains, Spotify, VirtualBox, Anaconda).

## Fixes

- The window no longer freezes while hundreds of photos or duplicates go to the Recycle Bin.
- The cleanup estimate is several times faster (about 8 s → under 2 s on the author's PC).
- The “Unknown” filter no longer shows every row while verdicts are loading.

## Safe by design

Nothing changes here: your files only go to the Recycle Bin, permanent deletion is limited to a public list of caches, the registry is never cleaned, and there is no account, ads or telemetry.
