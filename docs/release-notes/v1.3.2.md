**Kleaner 1.3.2.** A clearer Journal, on/off switches for startup programs, admin mode one click away, and fixes.

## Download

- **[Installer: kleaner-setup.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.3.2/kleaner-setup.exe)** (recommended): Start menu shortcut, uninstall from Windows Settings → Apps.
- **[Portable version: kleaner.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.3.2/kleaner.exe)**: a single file, nothing to install.
- Download page: **[swaks.org/kleaner](https://swaks.org/kleaner/)** · Scoop: `scoop install kleaner` (bucket in this repo).

Windows 10 or 11, 64-bit. Kleaner is not signed yet: if Windows says “Windows protected your PC”, click **More info**, then **Run anyway**. Each file has its SHA-256 next to it.

## New

- **Startup**: each program has an on/off switch instead of Turn on / Turn off buttons ([#4](https://github.com/Swaksm/Kleaner/issues/4)).
- **Journal**: actions are grouped by day, one line each with a readable name (“Sent to the Recycle Bin”, “Cleanup — Chrome cache”…). Click a line to see what was done, the files, the error or the command output ([#5](https://github.com/Swaksm/Kleaner/issues/5)).
- **Run as admin**: a button always visible under the Kleaner logo (it was hidden in Cleanup and Settings).
- **Privacy policy** linked next to the update check option.

## Fixes

- A Windows user name or a scheduled task name with a typographic apostrophe (’, as in “D’Artagnan”) broke the one-click update, “Start with Windows”, turning a startup task on or off, and the broken shortcuts search.
- **Tips** no longer suggests Kleaner's own portable exe as an old installer in Downloads.
- **Journal**: a refused restore point shows Windows' message instead of a technical line.
- Buttons aligned in **Scan** (both tables) and on **Home**; no more horizontal scrollbar in **Tips** (Steam games).

## Safe by design

Nothing changes here: your files only go to the Recycle Bin, permanent deletion is limited to a public list of caches, the registry is never cleaned, and there is no account, ads or telemetry.
