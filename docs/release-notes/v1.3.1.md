**Kleaner 1.3.1.** Fixes for sending many program leftovers to the Recycle Bin, plus quicker selection.

## Download

- **[Installer: kleaner-setup.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.3.1/kleaner-setup.exe)** (recommended): Start menu shortcut, uninstall from Windows Settings → Apps.
- **[Portable version: kleaner.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.3.1/kleaner.exe)**: a single file, nothing to install.
- Download page: **[swaks.org/kleaner](https://swaks.org/kleaner/)** · Scoop: `scoop install kleaner` (bucket in this repo).

Windows 10 or 11, 64-bit. Kleaner is not signed yet: if Windows says “Windows protected your PC”, click **More info**, then **Run anyway**. Each file has its SHA-256 next to it.

## Fixes

- **Program leftovers** now go to the Recycle Bin one folder at a time. One blocked folder (a file open in a program, a path that is too long) no longer cancels all the others: it is named with the reason and stays ticked so you can try again ([#3](https://github.com/Swaksm/Kleaner/issues/3)).
- **Recycle Bin too small**: before anything moves, Kleaner checks that the selection fits in the Recycle Bin of each drive, and explains what to do if it doesn't (otherwise Windows would delete the oldest items for good).
- **Tick everything shown** and **Untick all** in Program leftovers, Tips and Ghost entries.
- **Free space updates by itself** on Home and in Scan after every cleanup, Recycle Bin or move: no need to scan again to see the right number of GB.

## Safe by design

Nothing changes here: your files only go to the Recycle Bin, permanent deletion is limited to a public list of caches, the registry is never cleaned, and there is no account, ads or telemetry.
