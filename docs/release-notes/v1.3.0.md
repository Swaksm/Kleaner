**Kleaner 1.3.** A safety release: a full audit of everything that touches your disk, with fixes for OneDrive, the Recycle Bin, Windows.old and more.

## Download

- **[Installer: kleaner-setup.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.3.0/kleaner-setup.exe)** (recommended): Start menu shortcut, uninstall from Windows Settings → Apps.
- **[Portable version: kleaner.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.3.0/kleaner.exe)**: a single file, nothing to install.
- Download page: **[swaks.org/kleaner](https://swaks.org/kleaner/)** · Scoop: `scoop install kleaner` (bucket in this repo).

Windows 10 or 11, 64-bit. Kleaner is not signed yet: if Windows says “Windows protected your PC”, click **More info**, then **Run anyway**. Each file has its SHA-256 next to it.

## What's new

- **Waiting window during actions**: cleanups, Recycle Bin, uninstalls… show their progress and keep the app still until they finish. A cleanup can be stopped: items not started yet are skipped.
- **Windows support date by edition**: Enterprise, Education and LTSC (including IoT Enterprise LTSC) now get their real end-of-support date instead of the Home/Pro one. Windows 11 26H1 and 26H2 are known.
- **Apps that update themselves** (Epic Games, Steam, Battle.net, EA app, Ubisoft Connect, GOG Galaxy) are no longer sent to winget, which could never update them: Kleaner says to open the app instead.

## Fixes

- **Windows.old** is now deleted without `takeown` and `icacls`, which followed folder links into the running Windows and failed on German, Spanish, Italian and Portuguese Windows. Links are removed, never followed; permissions are not changed.
- **OneDrive and Dropbox** folders are no longer taken for links: their photos, videos and duplicates appear in Scan again.
- **Recycle Bin**: Kleaner refuses, before anything moves, a file that Windows would delete permanently (too big for the Recycle Bin, or a drive without one). A file deleted elsewhere since the scan no longer blocks the others.
- **Standard Windows account**: admin mode is refused with a clear message instead of closing Kleaner or running under another account.
- **Move to another drive**: a file created during the move is always copied; `desktop.ini` folders (Screenshots, Camera Roll) can be moved; an interrupted move is written to the Journal.
- **Journal**: Restore buttons of older actions no longer disappear after many cleanups.
- **Start with Windows**: the portable exe no longer starts with admin rights (only the installed version does); uninstalling removes the startup task; opening Kleaner again shows the window hidden near the clock.
- A network drive that does not answer no longer freezes the window; F5 and the right-click menu no longer reload the app.
- **Cleanups**: Dart/Flutter only removes downloaded packages (installed tools stay); Maven is never ticked automatically (it also removes libraries installed by hand); `.venv` is offered only next to a package list; old restore points keep the most recent one on each drive; new empty folders in `%TEMP%` stay.
- Health check texts are translated in every language.

## Safe by design

Nothing changes here: your files only go to the Recycle Bin, permanent deletion is limited to a public list of caches, the registry is never cleaned, and there is no account, ads or telemetry.
