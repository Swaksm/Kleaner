**Kleaner 1.1.2.** A clearer message when WebView2 is missing.

## Download

- **[Installer: kleaner-setup.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.1.2/kleaner-setup.exe)** (recommended): Start menu shortcut, uninstall from Windows Settings → Apps.
- **[Portable version: kleaner.exe](https://github.com/Swaksm/Kleaner/releases/download/v1.1.2/kleaner.exe)**: a single file, nothing to install.
- Download page: **[swaks.org/kleaner](https://swaks.org/kleaner/)** · Scoop: `scoop install kleaner` (bucket in this repo).

Windows 10 or 11, 64-bit. Kleaner is not signed yet: if Windows says “Windows protected your PC”, click **More info**, then **Run anyway**. Each file has its SHA-256 next to it.

## Fixes

- **Portable version on a PC without Microsoft WebView2**: instead of a technical error in English, Kleaner now explains, in the language of Windows, that WebView2 is needed and offers to open Microsoft's official installer. The installer (`kleaner-setup.exe`) already adds WebView2 by itself.
